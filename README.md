# Lovish Goyal Portfolio

Welcome to my personal portfolio website. This project is a modern, responsive, and highly polished showcase of my engineering skills, professional experiences, academic credentials, and software projects.

Developed with Next.js, React, TypeScript, and Framer Motion, it features smooth scroll animations, glassmorphism UI components, responsive layout alignments, and optimized SEO structure.

---

## Tech Stack & Features

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescript.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) & Vanilla CSS variables
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **SEO & Metadata**: JSON-LD Structured Data, OpenGraph, and Twitter Meta tags built-in.

---

## Project Structure

- `app/page.tsx` - Main page orchestrating the layout components.
- `app/Data/data.ts` - Centralized static data store containing all project details, experience timelines, credentials, skills, and links.
- `app/components/site/` - Modular site-wide section components (Hero, About, Experience, Education, Skills, Projects, Navbar, Footer).
- `app/components/ui/` - Reusable UI widgets and animation wrapper components (e.g., Reveal, Section).
- `public/` - Public assets including custom SVG project mockups and documents.

## Getting Started

### 1. Installation

Clone this repository and install the project dependencies:

```bash
npm install
```

### 2. Run Locally

Start the Next.js development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

### 3. Production Build

Verify TypeScript compilation and optimize build assets:

```bash
npm run build
```
